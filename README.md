## 🧠 Deep Learning for Caregiver Action Prediction
**Computer Vision | PyTorch**

Developed a deep-learning pipeline for predicting caregiver actions from RGB video frames.

- Processed **453,727 RGB frames**
- Produced **170,064 labeled frames**
- Modeled **17 caregiver action classes**
- Built a transfer-learning pipeline using **ResNet18**
- Used augmentation, fine-tuning, temporal aggregation, and Grad-CAM
- Achieved **54.56% test accuracy** versus a **16.18% majority-class baseline**

**Tech:** `Python` `PyTorch` `ResNet18` `Computer Vision` `Deep Learning` `Grad-CAM`
